TYNYS — GITHUB CODESPACES АРҚЫЛЫ ҚОРҒАУ

1. https://github.com/5kairosh/Tynys репозиторийін ашыңыз.
2. Code > Codespaces > Create codespace on master таңдаңыз.
3. 2 core / 8 GB машинасын пайдаланыңыз; тегін квотаның қалғанын тексеріңіз.
4. Контейнер жиналып, екі модель жүктелгенше күтіңіз.
5. Ports бөліміндегі 7860 порты: Port Visibility > Public.
6. Сол порттың https://...-7860.app.github.dev сілтемесін ашыңыз.

Бастапқы Dockerfile, requirements және модель файлдары қолданылады.
Сервер әр Codespace іске қосылғанда автоматты түрде қосылады.
Журнал: /tmp/tynys-codespaces.log
Қолмен қайта тексеру/іске қосу: python .devcontainer/start.py

Бұл — қорғау мен демонстрацияға арналған орта, тұрақты хостинг емес.
Codespace тоқтағанда сілтеме жұмыс істемейді. Қорғау аяқталғанда
GitHub Codespaces бетінен Stop codespace басып, тегін квотаны сақтаңыз.
Құпия деректер мен жеке пациент суреттерін жарияламаңыз.

Барлық функциялардың қашықтағы тексеруі жеке орындалған соң ғана
орындалды деп есептеледі; конфигурацияның болуы оны растамайды.

Жария сілтеме404, бірақ сервер дайын болса (6-кезеңде байқалды):
1. Terminal-да http://127.0.0.1:7860/api/status ready:true екенін тексеріңіз.
2. Ports-та7860 forwarding-ті тоқтатыңыз (Python серверін емес).
3. Forward a Port арқылы7860-ты қайта қосып, Port Visibility → Public таңдаңыз.
4. Жария root пен /api/status ашылатынын тексеріңіз. GitHub development-port
   хабарламасы шықса, өзіңіздің Codespace сілтемеңізде Continue арқылы өтіңіз.
Бұл Codespace тоқтауын немесе quota шектеуін шешпейді; Codespaces уақытша демонстрация.


7-кезең: сервер күйін ажырату
GET /api/health — процесс жауап беріп тұр (alive), модель сапасының дәлелі емес.
GET /api/ready — екі модель жүктелсе 200, болмаса 503.
GET /api/status -> service: active/waiting/admitted/accepting, тек агрегат санақтар.
429: орын толы; 503: кезек күтуі біткен; 504: есептеуді күтуі біткен.
Қосылым бар болса, суретті автоматты қайталамаңыз: хабарламадағы уақыттан соң
қайта басыңыз. Timeout underlying TensorFlow-ды тоқтатпайды, орны біткенше сақталады.
Егер сайт ашылмаса, алдымен Codespace іске қосылғанын және 7860 Public екенін
тексеріңіз. Healthcheck оны ұйқыдан оятпайды. Тұрақты хостинг әлі керек.
