TYNYS — КОМПЬЮТЕРГЕ ТӘУЕЛСІЗ АШЫҚ САЙТ

Күйі: Modal-ға жарияланды, 2026-10-21.
Қоғамдық сайт: https://kairosh--tynys.us-east.modal.run/
Жариялау панелі: https://modal.com/apps/kairosh/main/deployed/tynys
PNG/JPG/CR DICOM, Grad-CAM, үш модель, OOD және екі беттік PDF бұлтта тексерілді.
CT DICOM және мәтіннен жасалған жалған JPG дұрыс түрде HTTP 400 қайтарады.
Жергілікті тексеру: 131 серверлік және 48 браузерлік тест өтті.

ТЕГІН ШЕКТЕУЛЕР
Modal Starter: $0 тариф. Тариф бетінде ай сайын $30 кредит ұсынылады.
Бұл жаңа аккаунтта карта қоспай қолжетімді лимит — $1.
Usage & Billing > Usage limit: $1; карта қосылмаған, лимит көтерілмеген.
Қалған кредитті ашу үшін төлем әдісін қосу талабы көрсетілді; біз оны қоспадық.
Бұл шексіз тегін 24/7 сервер немесе қолжетімділік кепілдігі емес.
Бос кезде контейнер өшеді; келесі келуші ашқанда автоматты іске қосылады.
Алғашқы ашылуы модель жүктелгенше баяуырақ болуы мүмкін.
Кредит/лимит таусылса жұмыс тоқтауы мүмкін.
Тек тегін пайдалану: төлем әдісін қоспай, бар $1 лимитін сақтаңыз.
Егер аккаунтқа кейін төлем әдісі қосылса, spend limit = $0 орнатыңыз.
Төлем картасын, ақылы тарифті немесе автоматты толықтыруды қоспаңыз.
Егер платформа бұл аккаунтқа төлем жасауды міндеттесе, тоқтаңыз.
Ресурс: CPU 1, RAM 2 GiB, ең көбі 1 контейнер, ең азы 0.
Жасанды keep-alive сұраулары немесе жоспарланған ping қосылмайды.

МҮМКІНДІКТЕР
Бір FastAPI серверінде: JPG/PNG, CR/DX DICOM, үш модельді салыстыру,
Grad-CAM, OOD, сапа тексеруі, TXT/PDF, бірнеше файл, бағалау есептері.
HTTPS арқылы браузер тарихы, келісіммен сақтау, парольмен шифрлау,
қолмен және 5 минуттан кейін құлыптау сол frontend арқылы орындалады.
Тарих бұрынғы доменнен автоматты көшірілмейді; ол сол браузерде қалады.
Модель салмақтары, шектер, калибрлеу және медициналық шектеулер өзгермейді.

ДАЙЫНДАУ — РЕПОЗИТОРИЙ ТҮБІРІНДЕ
python -m venv .deploy-venv
.deploy-venv/Scripts/python -m pip install -r deployment/requirements-modal.txt
.deploy-venv/Scripts/python -m modal token new

Браузердегі ресми кіруді өзіңіз аяқтаңыз. Пароль/token-ді чатқа жібермеңіз.
Modal тіркелгісі мен ақы шектеуі дайын болған соң:
.deploy-venv/Scripts/python -m modal deploy -m deployment.modal_app

Дәл «deploy» қолданылады: «serve» жергілікті сессияға тәуелді уақытша нұсқа.
CLI берген https://...modal.run сілтемесін сақтаңыз; URL-ді ойдан құрмаңыз.

ЖАРИЯЛАНҒАННАН КЕЙІНГІ ТЕКСЕРУ
GET /api/status: ready, comparison_ready, dicom/xray_check/ensemble/mcnemar available.
PNG, JPG және CR/DX DICOM талдауы: 200; CT, бұзылған JPG: 400.
Grad-CAM PNG және үш модельдің болжамдары болуы керек.
Екі файлдан PDF: 200, %PDF, 2 бет.
Браузерде TXT/PDF/PNG жүктеу, топтық талдау, тарих пен парольді тексеріңіз.
Контейнер бос кезде тоқтаған соң сол URL-ді қайта ашып тексеріңіз.
