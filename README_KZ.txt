ҚҰРАМЫ
site/ — сайт коды, екі үйретілген модель, конфигурация, метрикалар және графиктер.
training/ — Google Colab-та үйретуге арналған ноутбук пен Python коды.
presentation/ — 10 слайдтық презентация және айтылым мәтіні.

ІСКЕ ҚОСУ
1. ZIP архивті толық шығарып ал. Архивтің ішінен тікелей іске қоспа.
2. Windows-та Python 3.11 орнатылған болуы керек.
3. site/start.bat файлын екі рет бас.
4. Алғашқы іске қосуда кітапханалар интернеттен орнатылады.
5. Сервер дайын болғанда http://127.0.0.1:7860 аш.
6. Сервер терезесін ашық қалдыр.

Модельдер дайын. Сайтты іске қосу үшін қайта үйрету қажет емес.
Соңғы нұсқада қосылымды автоматты қайта тексеру түзетуі бар.
