TYnys — толық жоба архиві
Жинақ күні: 2026-10-19

Бұл архивте сайттың коды, CNN және MobileNetV2 модельдері, модель конфигурациясы,
OOD параметрлері, оқыту ноутбуктері, метрикалар, тексеру дәлелдері,
Docker/Codespaces конфигурациясы, 13 слайдтық презентация және айтылым мәтіні бар.
Архивтегі RELEASE_MANIFEST.json әр файлдың SHA256 мәнін және Git commit-ін көрсетеді.

ЖЕРГІЛІКТІ ІСКЕ ҚОСУ
1. Архивті толық шығарыңыз. ZIP ішінен бағдарламаны іске қоспаңыз.
2. Python 3.11 орнатылған компьютерде Tynys/site/start.bat файлын ашыңыз.
   Алғашқы іске қосу интернет пен тәуелділіктерді орнатуды қажет етеді.
3. Терминалдағы сервер дайын деген хабардан кейін http://127.0.0.1:7860 ашыңыз.
4. Беттің сервер күйін тексеріп, JPG/PNG немесе қолдау көрсетілетін CR/DX DICOM жүктеңіз.
   Терминал жабылса немесе компьютер өшсе, жергілікті сайт тоқтайды.

DOCKER
Tynys түбірінен:
  docker build -t tynys .
  docker run --rm -p 127.0.0.1:7860:7860 tynys
7860 бос болмаса, -p 127.0.0.1:7861:7860 қолданып, браузерде 7861 портын ашыңыз.
Алдыңғы тексерудің дәлелдері training/docker_evidence/ ішінде.

ІСКЕ АСЫРЫЛҒАН НЕГІЗГІ ФУНКЦИЯЛАР
- NORMAL/PNEUMONIA классификациясы; CNN, MobileNetV2 және ensemble салыстыруы.
- Grad-CAM арқылы модель назарының жуық картасын көрсету.
- JPG/PNG және қолдау көрсетілетін CR/DX DICOM өңдеу; бірнеше файлды талдау.
- Белгіленген сурет, мәтін және PDF есеп жүктеу.
- Соңғы 20 талдауға қайта оралу; келісіммен осы браузерде сақтау, жеке/толық жою.
  Әдепкіде уақытша; сақтау қосылса 7 күнге дейін, 80 МиБ. Ортақ браузерде тарих көрінеді.
- Сақталған параметрлер арқылы калибрлеу және OOD ескертуі.
- Жеке «Сурет сапасы» блогы: жарықтық, контраст, өлшем, пішім және ұсақ деталь
  туралы техникалық ескертулер. Тарих пен TXT/PDF есептерде де көрсетіледі.
- OOD ауытқуы не тексерудің істен шығуы кезінде «Сенімді бағалау мүмкін емес»
  күйі сайтта, тарихта және TXT/PDF есептерде көрсетіледі. Бұл сақтық ережесінің
  клиникалық сапасы бағаланбаған; техникалық баллдар бөлек қалады.

Кейбір бұрынғы есептер мен презентациядағы орналастыру жоспары өз кезеңінің
күйін сипаттайды. Кейін қосылған Codespaces демонстрациясының күйі README.md,
.devcontainer/README_KZ.txt және осы файлда көрсетілген.

виртуалды орта, кэш, жүктелген пациент суреттері және Git дерекқоры қосылмаған.
Қайта оқыту үшін ноутбуктердегі деректерді алу қадамдарын орындау қажет.
