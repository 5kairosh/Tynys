TYNYS — 4-КЕЗЕҢ: OOD САҚТЫҚ ЕРЕЖЕСІН ӨЛШЕУ
Күні: 2026-10-20. Бұл жаңа модель үйрету емес; бекітілген ереженің сипаттамалық аудиті.

НЕГЕ ҚОСЫЛДЫ
Бұрын ood_guard_v1 ережесі OOD ауытқуы бар/тексерілмеген суреттерге қорытынды
бермейтін, бірақ оның қанша суретті өткізетіні мен қателігі өлшенбеген.
Енді сайттың «Зерттеу нәтижесі» бөлімінде ішкі тест пен сыртқы OpenI бөлек көрсетіледі.
Есеп JSON түрінде жүктеледі; қабылданған топ бос болса, accuracy есептелмейді.

БЕКІТІЛГЕН ӘДІС
MobileNetV2 ea584b998a45. Жіктеу шегі 0,745; T=0,9799594303292329.
OOD: 1280 белгі, shrinkage covariance, validation 952 суретіне fitted;
сол fitting жиынының 95-процентилі = 26,340902898169077.
Барлық параметр, модель салмағы және калибрлеу өзгерген жоқ.
RGB decode_image → float32 → resize_with_pad 224×224 → модельдің өз preprocessing-і.
OOD белгілері модельдің соңғы spatial feature картасының орташа мәнінен алынады.
Жарияланған болжаммен салыстырылған жаңа нақты forward pass қолданылды:
максимал балл айырмасы ішкі тестте 0,00001133, OpenI-де 0,00000305;
барлық бинарлы санаттар бастапқы архивпен бірдей.
Әр суреттің SHA256-ы тексерілді. Train/validation/test SHA және surrogate топ
қиылысы жоқ; OpenI мен ішкі деректердің байт SHA қиылысы жоқ.
Бұл бір пациенттің басқа түсірілімдері қайталанбайтынын дәлелдемейді.

НАҚТЫ НӘТИЖЕ
Ішкі тест: 618 сурет, NORMAL 231 / PNEUMONIA 387.
Барлығына мәжбүрлі екі санат берілгенде: 67/618 қате (10,84%), accuracy 89,16%.
Қорытынды берілді: 39/618 (6,31%); берілмеді: 579/618 (93,69%).
Қорытынды берілген 39 сурет: 6 қате (15,38%), accuracy 84,62%.
TN=23, FP=5, FN=1, TP=10; NORMAL 28 / PNEUMONIA 11.
Осы топтағы sensitivity 10/11=90,91%, specificity 23/28=82,14%.
Тоқтатылған 579 суреттің техникалық санаттарында 61 қате бар; олар сайт қорытындысы емес.

Сыртқы OpenI: 200 сурет, NORMAL 160 / PNEUMONIA 40.
Барлығына мәжбүрлі екі санат берілгенде: 90/200 қате (45%), accuracy 55%.
Қорытынды берілді: 0/200; берілмеді: 200/200.
Қабылданған топта сурет жоқ: accuracy/error/sensitivity/specificity = null.
«Қате жоқ, демек 100% дәл» деген қорытынды жасауға БОЛМАЙДЫ.

ТҰЖЫРЫМ ЖӘНЕ КЕЛЕСІ ЗЕРТТЕУ
Қазіргі ереже тым аз сурет өткізеді және осы аудит қателікті азайтуды растамайды.
Бұл шектеу сайтта көрсетіледі. OOD-тан өту дұрыс диагнозға кепіл емес.
Шекті test/OpenI нәтижесіне қарап өзгертуге немесе сол жиындарға бейімдеуге болмайды.
Келесі бөлек экспериментте reference белгілерін train-да бағалап, шекті бөлек
development/validation деректерінде бекіту, кейін жаңа тәуелсіз holdout-қа шығу қажет.
Сондай-ақ маман белгілеген сапа, X-ray/non-X-ray және бірнеше мекеме деректері керек.
Аудит — осы іріктемелердің сипаттамасы; себептік әсер, статистикалық маңызды
жақсару, клиникалық сенімділік және барлық рентгенге жалпылау расталмаған.
OpenI MeSH — report-level әлсіз белгі, клиникалық gold standard емес.
Файл атынан/есеп ID-інен алынған топтар longitudinal пациент ID емес.
Validation fitting деректері болғандықтан тәуелсіз тексеру ретінде көрсетілмейді.
Сапа эвристикасы advisory; ол қорытындыны тоқтататын ережеге қосылмады.
Аудит MobileNetV2-ге қатысты; CNN/Ensemble клиникалық сапасын растамайды.

ҚАЙТА ОРЫНДАУ (жоба түбірінен, Python 3.11)
site/.venv/Scripts/python training/download_validation.py --split test
site/.venv/Scripts/python training/evaluate_selective.py
site/.venv/Scripts/python -m pytest site/tests training/tests -q
Бірінші команда ресми Kaggle архивінен тек test манифестінің файлдарын жүктейді.
OpenI суреттері training/external_predictions.csv URL-дері бойынша жеке
training/cache/openi/<sha256(url)>.png кэшінде болуы керек; кэш Git/ZIP-ке кірмейді.
Толық external_validation.py қайта іске қосылса, ол басқа есептерді жаңартуы мүмкін;
осы аудит бұрыннан бекітілген 200 суреттен ғана оқиды, жүктемейді/іріктемейді.
Жартылай жиынға есеп жарияланбайды; SHA/болжам сәйкестігі бұзылса, скрипт тоқтайды.

АРТЕФАКТТАР
site/model/selective_evaluation.json — агрегаттар, параметрлер және provenance SHA.
training/selective_evaluation/internal_test.csv және external_openi.csv — тек сандық
нәтиже мен сурет SHA-лары. Сурет пиксельдері, feature массивтері жарияланбайды.
/api/status.selective_evaluation — runtime тексерген есеп.
Модель, OOD, config немесе байланысты Python коды сәйкес болмаса есеп өшеді;
негізгі сурет талдау қызметі сақталады. Python кодының SHA-сы CRLF→LF арқылы
платформаға тәуелсіз есептеледі; model/config/NPZ байттары өзгертілмейді.
Жүктелетін JSON — осы параметрлермен өлшенген есеп; пайдаланушы суретінің диагнозы емес.
