ТАЛДАУ ТАРИХЫН САҚТАУ — 3-КЕЗЕҢ (2026-10-19)

ПАЙДАЛАНУ
1. Суретті талдаңыз. Әдепкіде нәтиже тек ашық бет жадында қалады.
2. «Тарихты осы браузерде сақтауға келісемін» жалаушасын өзіңіз қосыңыз.
   Қосқанда осы беттегі қазіргі тарих пен келесі талдаулар сақталады.
3. Бетті жаңартып, тарихтағы «Қайта ашу» батырмасын басыңыз.
   Түпнұсқа файл, бұрынғы нақты балл, модель ID, сапа/OOD және Grad-CAM нәтижесі
   қайта есептелмей қалпына келеді. Модель ID өзгерсе, бұрынғы нәтиже екені жазылады.
4. Бір талдауды «Жою» арқылы немесе барлық тарихты «Тарихты тазалау» арқылы өшіріңіз.
   Барлығын тазалау сақтау келісімін де өшіреді. Бірнеше қойындыдағы тарих жаңарады.
5. Жалаушаны өшірсеңіз, браузердегі сақталған көшірмелер жойылады, осы беттегі
   уақытша тарих қалады. Бетті жаңартқанда уақытша тарих та жоғалады.

ҚАЙДА ЖӘНЕ НЕ САҚТАЛАДЫ
Осы сайттың осы браузер профиліндегі IndexedDB қоймасы ғана: tynys-history-v1.
Түпнұсқа JPG/PNG/DICOM файлы, файл атауы, талдау уақыты және API нәтижесі.
DICOM ішіндегі бастапқы метадеректер де файлда сақталады.
Серверде тарих базасы немесе пациент суреттерінің тұрақты көшірмесі жасалмайды.
Cookie немесе localStorage қолданылмайды. Басқа браузер, профиль, домен не порт
осы тарихты автоматты түрде алмайды. Есептік жазба және құрылғылар арасында синхрондау жоқ.

ШЕКТЕР
- Соңғы 20 талдау; сақталатын түпнұсқа файлдар мен нәтижелерге шамамен
  80 МиБ шек (83 886 080 байт), әр жазбаға 2048 байт қосымша есептік қор.
  Шек асса, ескі жазбалар сақталған жиыннан шығарылады.
- Жазба талдау уақытынан 7 күн өткен соң жарамсыз. Сайт ашылғанда, назар оған
  ауысқанда және сақтау қосулы кезде минуттық тексеруде мерзімі өткендер жойылады.
  Сайт жабық тұрғанда физикалық тазалау жүрмейді: келесі ашқанда іске асады.
- Браузер сақтау орнын босатып, деректерді ертерек өшіруі мүмкін. Бұл backup емес.
- Жеке қосымша шифрлау мен пароль жоқ. Осы құрылғыдағы осы браузер профилін
  пайдаланатын басқа адамдар тарихты көре алады. Ортақ құрылғыда сақтауды қоспаңыз.

ҚАТЕЛЕР ЖӘНЕ БІРНЕШЕ ҚОЙЫНДЫ
Деректер IndexedDB транзакциясы толық біткеннен кейін ғана «сақталды» деп белгіленеді.
Орын жетпесе немесе сақтау бұғатталса, нәтиже «Тек осы бетте» болып қалады.
Браузер деректерін жою қатесі болса, сайт жойылғанын растамайды; қайта жоюға болады.
Келісімнің generation таңбасы басқа қойынды тазалағаннан кейін ескі жазу сұрауының
өшірілген суреттерді қайта сақтап жіберуіне жол бермейді.
BroadcastChannel арқылы тек «өзгерді» сигналы тарайды, суреттер жіберілмейді.
Сақталған жазбаның форматы тексеріледі; жарамсыз не мерзімі өткен жазбалар алынады.

ЕСЕПТЕР
Тарихты ашу қайта inference сұрауын жібермейді. TXT және белгіленген суретті
жүктеу бұрынғы нәтиженің деректерін қолданады.
PDF батырмасы бастапқы файлды серверге қайта жібереді және ағымдағы модельмен
қайта есептейді. Бұл әрекет батырма жанында түсіндірілген; PDF бұрынғы нәтиженің
өзгермейтін архиві ретінде ұсынылмайды. Сервер қосылмаса PDF қайта есептелмейді.
Сервер API жұмыс істемесе де жүктеліп тұрған сайтта бұрынғы нәтижені ашуға болады;
сайттың өзі толық offline PWA ретінде жасалмаған.

ТЕКСЕРУ
Сервер/модель: site/.venv/Scripts/python -m pytest site/tests training/tests -q
Браузер (Node.js 22+, Chromium):
  cd site/tests/browser
  npm ci
  npx playwright install chromium
  npm test
Браузер сынақтары нақты Chromium/IndexedDB қолданады, inference API-і синтетикалық
жауаппен алмастырылған. Олар медициналық дәлдікті өлшемейді. Нақты модельмен бөлек
сурет талдау, бетті жаңарту және нәтижені қайта ашу тексеріледі.

КОД
site/static/history-storage.js — транзакциялар, сақтау шектері, келісім, мерзім.
site/static/app.js — келісім интерфейсі, тарихты ашу, жою және қойындыларды жаңарту.
Модель, калибрлеу, шешім шегі, OOD және сапа алгоритмі өзгертілмеген.
